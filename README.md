# nsh.editz — Website Toko Digital

Website statis 4 halaman untuk prototipe toko produk digital dan jasa edit.

## Isi folder
- `index.html` — landing page / Home
- `products.html` — katalog produk digital dengan filter dan pencarian
- `services.html` — daftar jasa edit dan contoh harga
- `contact.html` — formulir order yang menyiapkan pesan WhatsApp
- `style.css` — desain soft blue + lilac dan responsif untuk HP/laptop
- `script.js` — menu HP, dark mode, filter produk, dan formulir order

## Sebelum dipublikasikan
1. Buka `script.js`.
2. Ganti `WHATSAPP_NUMBER = "6281234567890"` dengan nomor WhatsApp tokomu (format kode negara, tanpa `+` atau spasi).
3. Sesuaikan harga contoh, deskripsi produk, username, dan kebijakan penggunaan template.
4. Uji semua tautan dan formulir.

## Upload ke GitHub
1. Buat repository baru, misalnya `nsh-editz-store`.
2. Upload semua file di folder ini langsung ke root repository (jangan hanya upload ZIP).
3. Pastikan `index.html` ada di root.
4. Buka Settings → Pages.
5. Pilih `Deploy from a branch`, branch `main`, folder `/(root)`, lalu Save.
6. Tunggu beberapa menit dan buka URL yang diberikan GitHub Pages.

## ZIP
Untuk mengumpulkan tugas, kompres folder ini menjadi ZIP. ZIP bukan pengganti upload file website ke root repository.

## Catatan
Ini adalah prototipe katalog. Tidak ada pembayaran otomatis, database, atau pengiriman produk otomatis. Pesanan masih perlu dikonfirmasi manual. Harga yang ditampilkan hanya contoh dan harus disesuaikan.
